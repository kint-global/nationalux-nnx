# NNX Whitepaper 2.0 — Public Summary

## Vision
**NNX — The Utility Layer for the AI & Data Economy**

NNX is an existing Ethereum token originally deployed in 2020. Nationalux is expanding the token's intended utility from the original digital-content economy toward a broader ecosystem involving data, AI services, digital content, enterprises and users.

## Ecosystem
Data Providers → Data Processing / AI-Ready Data → AI Services → Economic Value → NNX Utility

NNX may support ecosystem functions such as service access, rewards and settlement where implemented by participating services and subject to applicable agreements and law.

## Governance boundary
Holding NNX does not by itself provide shares, director-election rights, dividends or ownership of Nationalux Lab Inc.

## Market boundary
No fixed fiat value, guaranteed redemption, guaranteed liquidity, investment return or exchange listing is promised.
