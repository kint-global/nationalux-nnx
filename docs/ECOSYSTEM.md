# NNX Ecosystem

## Data Economy
NNX is designed to support a network in which independent data providers can connect data resources to catalogs, AI-ready processing and service access.

## AI Service Economy
AI models, agents, analytics and enterprise applications can participate as service providers or consumers.

## Media Economy
The original Nationalux creator/viewer reward concept remains a supported ecosystem vertical.

## Growth model
Connect → Standardize → Create Utility → Grow Usage → Add Data / Partners → Repeat

Corporate acquisitions, investments or roll-ups are separate corporate transactions. NNX ownership does not create ownership rights in Nationalux or acquired companies.
