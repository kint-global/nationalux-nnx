# NNX Technical Roadmap

This document separates **current verifiable state** from planned modules.

## Current / Verifiable

- Existing NNX ERC-20 deployment on Ethereum Mainnet.
- Public contract address and creation transaction.
- Read-only token integration through the published ABI.
- Mainnet state verification script for identity, supply, pause status and administrative roles.
- Deterministic SHA-256 dataset-metadata hashing example.

## Roadmap / Not Yet Represented as Production Deployment

- Decentralized metadata/integrity references using technologies such as IPFS or Arweave where appropriate.
- Privacy-preserving data verification using TEE and/or zero-knowledge methods where technically justified.
- Dedicated NNX escrow or conditional-settlement contracts.
- REST/gRPC interfaces for machine-readable data/AI access.
- EIP-712 signed machine-to-machine workflows.
- Safe-compatible multi-signature administrative control.
- Verifiable treasury time-lock/vesting contracts for approved material allocations.

Each roadmap item should move to “deployed” status only after executable code, security review where appropriate, deployment references and public documentation are available.
